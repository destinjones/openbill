# Code of conduct

OpenBill adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Read it there; it applies here in full, including its enforcement
guidelines.

## What this means here

OpenBill is about money and health, and people feel strongly about both. Argue about
numbers, sources and methods as hard as you like. Don't attack people.

## Scope

Every space the project runs: issues, pull requests, reviews, commits, discussions, and
anywhere a maintainer speaks for the project.

That includes discussions about data: wrong-price reports, arguments over a source or a
method, and anything said about the companies, pharmacies and agencies that appear in the
data. Criticise the data and the decisions, not the people who made them or who reported
them. Never post someone else's health information, and post only as much of your own as a
report needs.

## Reporting

Report a problem privately to a maintainer listed in [GOVERNANCE.md](GOVERNANCE.md). Until
the project has a dedicated address, use GitHub: choose **Report content** on the comment,
issue or pull request, and send it to the repository's maintainers if GitHub offers that.
If the problem is with a maintainer, or the report is urgent, report it to GitHub directly
from the same menu.

Maintainers keep the reporter's identity private, and a maintainer involved in a report
takes no part in handling it.
